🛒 Shopping Cart Web Application

A simple and responsive shopping cart website built using HTML, CSS, and Bootstrap to provide a clean and user-friendly shopping experience.

✨ Features

- 📱 Responsive and modern design
- 🔐 Login and registration pages
- 🛍️ Shopping cart page
- 🎨 Bootstrap-based styling

🛠️ Tech Stack

HTML • CSS • Bootstrap

🚀 How to Run

1. Download or clone the repository.
2. Open "index.html" in your browser.
3. Explore the website!

🎯 Objective

To develop a responsive shopping cart web application using Bootstrap.
